# 📊 Business Sales Performance Analytics - Task 1

## 📌 Project Overview
The **Business Sales Performance Analytics** project focuses on analyzing an organization’s sales and profit performance using interactive Tableau dashboards. 
The objective of this task is to evaluate historical sales data to identify key trends, regional contributions, profitability patterns, monthly revenue behavior, and category-wise product performance.
The project transforms raw transactional data into meaningful visual insights that support strategic decision-making, performance tracking, and business planning.

## 🧰 Tools & Technologies
- Tableau Desktop Public Edition
- Microsoft Excel (Cleaned Dataset)

## 📁 Dataset
The dataset consists of cleaned Superstore sales data, including:
- Order Date and Ship Date
- Sales, Profit, Quantity, and Discount
- Region, Category, Sub-Category, and Product details

## 📊 Dashboard Highlights
1. Year-wise Sales Analysis
2. Profit Analysis as per Ship Date
3. Monthly Revenue Analysis
4. Average Sales Analysis
5. Category-wise Product Sales Analysis
6. Segmentwise Sales and Profit
7. Percentage Contribution of Regions

## 🔍 Key Insights
- Sales and profits have consistently improved over time.
- A small number of regions and products contribute a major share of revenue.
- Seasonal patterns influence both sales and profitability.
- Category-wise and product-wise analysis helps identify high-value business areas.

## 📈 Conclusion
The **Business Sales Performance Analytics** dashboard provides a comprehensive view of business performance across time, regions, and product categories. The insights derived from this analysis enable data-driven decision-making, improve forecasting accuracy, and help optimize sales and profitability strategies.
